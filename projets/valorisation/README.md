# Valorisation des études

Projet suivi dans l'espace Grist [gestion de projets](../../espaces/gestion-projets/)
(ligne de `Projets2`). Les informations de valorisation sont portées par des
colonnes de `Projets2` (`Plus_value_Cerema`, `Exemple_de_resultat`,
`Duplicable`, `image`, `Latitude` / `Longitude`…) et par la table
`Info_valorisation_projet`.
